# eSearch 新手使用指南

这份文档写给第一次接触这个项目的人。全程照着做就行，不需要理解原理。

---

## 0. 先搞清楚一件事

你手上的是**源代码**，不是装好的软件。

所以不能像普通软件那样双击图标打开，必须先用一条命令把它"跑起来"。跑起来之后，它就是一个正常的 Windows 软件了。

好消息是：环境已经全部准备好了。Node、pnpm、Electron 都已经装好，你只需要执行启动命令。

---

## 1. 打开命令行窗口

**Windows 上最省事的办法（推荐）**：

1. 打开文件资源管理器，进入 `D:\SaveHub_Zcode\eSearch` 这个文件夹
2. 点击窗口顶部**地址栏**（显示路径的那一栏）
3. 把里面的路径全选删掉，输入 `cmd`，按回车
4. 会弹出一个黑色的命令行窗口，而且**已经在这个文件夹里了**

**其他办法**：按 `Win + R`，输入 `cmd`，回车，然后手动进入文件夹（见下一步）。

---

## 2. 进入项目文件夹

如果你用的是上面推荐的办法，这一步已经自动完成了，**直接跳到第 3 步**。

如果不是，在命令行窗口里输入下面这行，然后回车：

```
cd /d D:\SaveHub_Zcode\eSearch
```

> 注意：`cd` 后面有个空格，然后是 `/d`，再一个空格，然后是路径。  
> 如果你用的是 PowerShell 而不是 cmd，`/d` 要去掉，直接写 `cd D:\SaveHub_Zcode\eSearch`。

怎么确认自己进对地方了？输入 `dir` 回车，如果能看到 `package.json` 这个文件，就对了。

---

## 3. 启动软件

输入这一行，回车：

```
pnpm run start
```

然后会发生这些事：

1. 终端里刷出一堆文字 —— 这是**正常的**，它在编译代码
2. 大约 **10 秒左右**编译完成
3. 任务栏上出现一个**最小化**的按钮，名字是「eSearch 剪贴板历史」；右下角出现托盘图标

**不会有窗口自动弹出来**，这是正常的 —— 软件在后台待命，等你点任务栏按钮。

**重要：这个黑色终端窗口不要关。** 它是软件的"发动机"，关掉软件就退出了。

## 4. 启动后你应该看到什么

- **屏幕右下角**（托盘区，就是显示时间那一排图标里）多了一个 **eSearch 图标**，是彩色的
- **任务栏**上出现一个**最小化**的按钮，名字叫「**eSearch 剪贴板历史**」

**这个任务栏按钮就是控制中心本身。** 点它，控制中心就出来 —— 那是整个软件的主窗口，剪贴板记录、所有功能都在里面。

不会自动弹出任何窗口，这是故意的 —— 软件在后台待命，等你点它。

> 任务栏上**不会**有搜索框那个窗口。那是「主页面」，只在 OCR / 搜索 / 翻译需要时才出现，关掉就消失。

如果你没看到托盘图标，点一下托盘区左边的 `∧` 小箭头，展开隐藏的图标看看。

## 5. 启动失败了怎么办

### 情况 A：报错里有 `GPU process isn't usable`，或者窗口一闪就没了

这是显卡加速在你的机器上不兼容。**关掉硬件加速就好了**：

1. 打开这个文件（复制路径到文件资源管理器地址栏）：


   ```
   C:\Users\86183\AppData\Roaming\eSearch\config.json
   ```
2. 用记事本打开它（右键 → 打开方式 → 记事本）
3. 找到这一行：
   ```json
   "硬件加速": true,
   ```
4. 把 `true` 改成 `false`，变成：
   ```json
   "硬件加速": false,
   ```
5. 保存（Ctrl+S），关掉记事本
6. 回到命令行，重新执行 `pnpm run start`

> 也可以等软件能正常打开后，在「设置 → 高级」里把「硬件加速」关掉，效果一样。

### 情况 B：提示 `'pnpm' 不是内部或外部命令`

你的电脑没装 pnpm。在命令行里执行：

```
npm i -g pnpm
```

装完再执行 `pnpm run start`。

### 情况 C：提示 `Cannot find module 'electron'`

Electron 的程序文件没下载全。在项目文件夹里执行：

```
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
pnpm install
```

这会从国内镜像重新下载（大约 100 多 MB），下完再启动。

### 情况 D：终端停住不动了

大概率是还在编译，**再等 20 秒**。第一次编译会慢一些。

## 6. 两个入口：托盘 + 任务栏

这是你要的第一个功能。**两个入口通向同一个东西 —— 控制中心（软件的主窗口）。**

**任务栏按钮**（名字是「eSearch 剪贴板历史」）

- 点它 → 控制中心出现（默认显示剪贴板记录）
- 点右上角的 **×** → 窗口缩回任务栏，**按钮一直留着**，随时再点开

**托盘图标**（右下角）

- **左键点击**：快速截屏（直接进截图框选，这是软件本来的设计）
- **右键点击**：弹出菜单，只有 4 项 —— **打开控制中心 / 快速截屏 / 暂停记录 / 退出**。其他所有功能都在控制中心左边的**工具组**里

**关键一点：点窗口的 × 不会让软件退出，也不会让任务栏按钮消失。**

它只是收起来了。想真正退出，用托盘右键菜单里的「退出」。

**那搜索框呢？** 那是「主页面」，只在 OCR、搜索、翻译需要时才自动弹出，**不常驻任务栏**，关掉就消失。

## 7. 剪贴板历史怎么用

这是你要的第二个功能。

### 打开控制中心

三种方式，效果一样：

1. **点任务栏上的「eSearch 剪贴板历史」按钮**（最方便）
2. **右键点托盘图标** → 点菜单里的 **「打开控制中心」**
3. 第一次启动时右下角弹出的**系统通知**，直接点它

控制中心是一个**独立窗口**，默认约 1100 × 720，可以随意拖动和缩放。**位置和尺寸都会被记住**，下次打开还是老地方。打开后左边是侧边栏（剪贴板 / 翻译 / AI 识图 / 设置四个栏目 + 工具组），右边默认就是剪贴板记录列表。

> 如果你换了显示器、拔了外接屏或者改了分辨率，导致上次的位置跑到屏幕外了，控制中心会自动回到屏幕中间，不会"消失不见"。

> 想让控制中心每次都以固定大小出现（比如半屏、全屏）？见下面的「设置 → 剪贴板历史 → 点击任务栏时的尺寸」。

### 控制中心长什么样

窗口最顶上是一条**顶栏**：左侧是**快速截屏 / 自动识别 / 回到剪贴板**三个快路径，中间显示"**正在记录 / 已暂停**"，右侧的**暂停图标**临时停止记录（再点一下恢复）。

剪贴板页从上到下：

| 位置 | 作用 |
| -- | -- |
| 页头右侧：**回收站** | 切换到「回收站」视图，看已删除的记录 |
| 页头右侧：**清空** | 一键清空所有未固定的记录（会二次确认） |
| **搜索框** | 输入关键词筛选记录（只对文字和文件路径有效） |
| **类型筛选**：全部 / 文本 / 图片 / 文件 | 每个都带着条数；点"文本""图片""文件"可多选（比如"文本 + 图片"），点"全部"回到全部 |

> **为什么需要类型筛选？** 因为**图片没有文字可以搜**。搜索框对图片记录是无效的，想只看图片就用筛选。

筛选和搜索可以**叠加使用**：先点「文本」，再在搜索框输入关键词，就是"在文本记录里搜关键词"。

下面就是记录列表，按「固定 / 今天 / 昨天」分组。每行左边是**时间**，中间是内容摘要（图片显示缩略图），右侧是操作图标：

| 图标 | 出现条件 | 作用 |
| -- | ---- | -- |
| 复制 | 都有 | 把这条内容放回系统剪贴板，之后在别的地方 Ctrl+V 就能粘贴；**双击这一行**也是复制 |
| 眼睛 | 只有图片 | **放大看原图**（见下面「放大看图片」） |

行尾小提示写着"**单击 / ↑↓ 选择 · 双击复制**"。**单击**一条记录（或按 ↑↓ 键），右边会展开这条记录的**记录纸**——详情面板，有标题、时间、内容全文，以及这些按钮：

| 按钮 | 出现条件 | 作用 |
| -- | ---- | -- |
| 复制 | 都有（绿色主按钮；文件记录写"复制路径"） | 放回系统剪贴板 |
| 放大查看 | 只有图片 | 弹层看原图 |
| 固定 / 取消固定 | 都有 | **固定**这条记录（固定后不会被自动清理淘汰）。固定后星标变成**金色实心**，卡片左侧多一道金色色带、底色微暖，并且会排到列表最前 |
| 编辑 | 只有文本 / 文件 | **改这条的内容**（见下面「改一条记录的内容」） |
| 删除 | 都有 | 删除 → 进回收站（不是真删） |

> 图片没有"文字内容"可改，文本没有"原图"可看 —— 所以"编辑"不给图片、"放大查看"只给图片。

在**回收站**视图里，记录行上没有操作图标——**单击**一条，还是在右侧**记录纸**里点**恢复**（还原回去）或**永久删除**（真删，不可恢复）。

### 改一条记录的内容

复制来的文字常常带多余的前后缀，或者只错一个字。以前只能删掉重新复制，现在可以直接改：

1. **单击**这条记录，在右侧的**记录纸**里点**编辑**
2. 内容块就地变成输入框，直接改（文件记录是"一行一个路径"）
3. 点**保存**（对勾图标）生效，点**取消**（返回图标）放弃

几个约定：

- **只有文本和文件记录能改，图片不能**
- **不能改成空的**：把内容清空后点保存不会生效，会留在编辑状态让你改回来
- **改完如果和另一条记录一模一样，两条会合并成一条**（被合并那条的"固定"状态会保留下来）
- **回收站里的记录不能改**

### 放大看图片

图片记录在列表里只显示一张缩略图。想看原图，点行右侧的**眼睛图标**，或在记录纸里点**放大查看**——会弹出一张大图，按 `Esc` 或者点图片外面的灰色区域就能关掉。**大图下面有一个「复制」按钮**，看完直接点它，这张图就回到系统剪贴板了（复制后大图会自动关掉）。

### 亲手试一遍

1. 随便找一段文字，选中，Ctrl+C 复制
2. 打开控制中心（如果已经开着，它会自动刷新，不用手动操作）
3. 你应该能看到刚复制的那段文字出现在列表最上面
4. 点那条记录右边的**复制图标** —— 内容回到剪贴板了（**双击**这一行也一样）
5. **单击**那条记录展开记录纸，点**编辑**，改两个字，再点**保存** —— 内容就地变了
6. 在记录纸里点**固定**，它会保持在列表里不被清理
7. 在记录纸里点**删除**，然后点页头右侧的**回收站**进回收站视图；**单击**那条记录，点**恢复**找回来，或者**永久删除**彻底删掉
8. 随便复制一张图片，回到控制中心**单击**那条记录——在记录纸里点**放大查看**看原图，再点原图下面的**复制**，这张图就复制好了

### 控制中心会不会挡住别的窗口？

**平时会置顶**，这样你随手唤出来它就在最上面，不会一碰别的窗口就被盖住。

**但 OCR、搜索、翻译的结果窗口出现时，控制中心会自动让到后面去**，不会挡住它们。这些窗口关掉后，控制中心又恢复置顶。

> 反过来说：**搜索窗口本身不置顶**，它是正常窗口。

### 复制图片和文件路径也支持

- 复制一张图片（比如在网页上右键复制图片）→ 控制中心的记录列表里会出现缩略图
- 在文件资源管理器里选中一个文件，Ctrl+C → 列表里会显示这个文件的完整路径

### 第一次启动会有一条系统通知

右下角会弹一条通知，告诉你"已开始记录你复制的文字、图片和文件路径"。这是为了让你知道这个功能默认是开着的，**不是病毒行为**。点它可以直接打开控制中心。

## 8. 设置项说明

打开软件后，进「**设置 → 剪贴板历史**」，有这些选项：

| 设置项         | 默认值    | 说明                                        |
| ----------- | ------ | ----------------------------------------- |
| **记录剪贴板**   | 开      | 总开关。关掉就完全不记录了                             |
| **轮询间隔**    | 500 毫秒 | 多久检查一次剪贴板。数字越小越及时，但更耗电。**建议保持默认**         |
| **点击任务栏时的尺寸** | 默认     | 点任务栏打开控制中心时用多大。可选 **默认**（沿用你上次调的大小）/ **50%** / **75%** / **100%**（最大化）。百分比以屏幕工作区为准，不会压住任务栏 |
| **存储目录**    | 留空     | 留空就存在程序自己的数据目录里。改成别的文件夹后，**已有的记录会自动迁移过去** |
| **保留条数**    | 200    | 最多留多少条。固定住的记录和回收站里的**不算在内**。填 0 表示不限制     |
| **保留天数**    | 7      | 超过这个天数的记录会被清理。填 0 表示不限制                   |
| **清空剪贴板历史** | —      | 一个按钮，点它清空所有**未固定**的记录（固定的会留着）。会弹窗二次确认     |

> **「点击任务栏时的尺寸」怎么理解**：选 `默认` 时，控制中心还是"记住你上次调的大小"；选了百分比之后，每次打开都会强制拉成那个尺寸，而且**这时你手动拖的大小不再被记住**——因为档位说了算。切回 `默认`，会恢复到你最后一次在 `默认` 档下调出来的尺寸。

改完这些设置**大约 1 秒后自动生效**，不需要重启软件。

## 9. 数据存在哪里 + 加密

### 默认位置

```
C:\Users\86183\AppData\Roaming\eSearch\剪贴板历史\
```

里面有三个东西：

| 文件                     | 内容                       |
| ---------------------- | ------------------------ |
| `index.bin`            | 所有记录的索引（文字内容、时间、是否固定等）   |
| `images\` 文件夹          | 图片记录的原始数据，每条一个 `.bin` 文件 |
| `clipboardHistory.key` | 加密用的密钥（在上一级目录）           |

### 加密说明

记录**不是明文存的**，用的是 **AES-256-GCM** 加密。密钥本身由 Windows 系统级的凭据保护（safeStorage）加密后才落盘。

**这意味着什么**：别人直接把 `index.bin` 拷走，是打不开的。

**但要如实告诉你两点**：

1. 这**只保护"落盘不明文"**。如果你的电脑已经中了木马、或者有人能直接操作你的电脑，这个加密挡不住。
2. 如果系统不支持加密（极少数情况），软件会**降级成明文保存**，同时在设置页顶部显示一条**黄色提示条**明确告诉你。**看到提示条就要知道：你的记录是明文的。**

> 自己手动删掉 `clipboardHistory.key` 会导致已有记录全部无法解密，**不要删**。

## 10. 怎么退出软件

**托盘图标右键 → 退出**。

注意：点控制中心的 × **不会**退出，只会把它缩回任务栏 —— 这是故意的，为了让任务栏按钮一直可用。

主页面（搜索框那个窗口）的 × 会**真正关掉那个窗口**，但软件本身还在 —— 任务栏按钮和托盘图标都不受影响。下次 OCR / 搜索时它会再自动出现。

## 11. 给开发者：改代码之后怎么调试

| 命令                   | 作用                           |
| -------------------- | ---------------------------- |
| `pnpm run dev`       | 开发模式，改代码后界面会自动刷新，**平时开发用这个** |
| `pnpm run start`     | 构建后启动，接近真实运行效果               |
| `pnpm run typecheck` | 检查 TypeScript 类型错误           |
| `pnpm run lint`      | 检查代码风格问题                     |
| `pnpm run build`     | 只构建，不启动                      |
| `pnpm run pack`      | 打包成免安装程序（见第 12 节）            |

> 提示：这个项目的 `lint` 用的是 Biome。如果你看到大量关于换行符（CRLF / LF）的报错，那是 git 的 `core.autocrlf` 设置导致的，不是你的代码写错了。用 `npx biome lint src/` 可以只检查不格式化。

## 12. 打包成安装包（做成 .exe，双击就能装）

上面 `pnpm run start` 的用法只适合自己用。想**双击图标就用**，需要"打包"一次。

打包有**两种形态**，命令只差一个参数：

| 形态 | 命令 | 产物 | 什么时候用 |
| --- | --- | --- | --- |
| **安装包**（推荐） | `pnpm run dist` | `esearch_paste-15.6.1-win32-x64.exe` | 平时用。有安装向导、进"添加或删除程序"、自动建快捷方式 |
| 免安装目录 | `pnpm run pack` | `build\win-unpacked\e-search.exe` | 想放 U 盘带着走，或不想让程序写注册表 |

下面主要讲**安装包**。

### 三步操作

**第 1 步**：打开命令行，进入项目文件夹（和第 1、2 步一样）：

```
cd /d D:\SaveHub_Zcode\eSearch
```

**第 2 步**：执行打包命令：

```
pnpm run dist
```

然后**耐心等**。这一步会做三件事：编译代码、组装程序、生成安装包。整个过程大概 **3 ~ 10 分钟**，终端里会刷很多文字，都是正常的。

> 打包需要的 5 个大文件（OCR 模型、ffmpeg 等，共约 155 MB）**已经提前下载好了**，这一步不会再重复下载。
>
> NSIS 打包工具也已经缓存在本机（`%LOCALAPPDATA%\electron-builder\Cache`），不用联网。
>
> 也不需要配任何镜像 —— GitHub 直连是通的。

**第 3 步**：等终端重新出现命令提示符，就打包完成了。

### 产物在哪

打开 `D:\SaveHub_Zcode\eSearch\build\`：

| 文件 | 大小 | 是什么 |
| --- | --- | --- |
| **`esearch_paste-15.6.1-win32-x64.exe`** | 约 184 MB | **安装包**，双击它开始安装 |
| `esearch_paste-15.6.1-win32-x64.zip` | 约 243 MB | 免安装压缩包，解压后和 `win-unpacked` 一样 |
| `win-unpacked\` | 约 565 MB | 解包目录，安装包就是从它压出来的 |

> 文件名里的 `15.6.1` 是**版本号**，每次发版都会变 —— **以 `build\` 里实际出现的文件名为准**（本指南的例子不一定跟得上最新版本）。
>
> 文件名带 `esearch_paste` 前缀是故意的：官方版叫 `eSearch-<版本>-win32-x64.exe`，不加前缀容易和它混。
>
> 前缀**只改文件名**，程序内部的名字、安装位置、数据目录全都没变（见下面「数据不会丢」）。

### 怎么安装

双击 `esearch_paste-15.6.1-win32-x64.exe`，然后：

1. 如果 Windows 弹出蓝色的 **「Windows 已保护你的电脑」** 提示 —— 点左边的 **「更多信息」**，再点 **「仍要运行」**。
   > 这是因为程序没有买代码签名证书（一年几百到上千元），所有个人开发的小工具都会这样，**不代表程序有毒**。
2. 出现安装向导，选安装目录。**默认是 `C:\Users\86183\AppData\Local\Programs\eSearch`**，直接点「下一步」就行，也可以点「浏览」换成别的盘。
   > **不需要管理员权限**，不会弹 UAC 确认框。
3. 一路「下一步」→「安装」→「完成」。装完会自动启动一次，桌面上和开始菜单里都会有快捷方式。

### 装新版时，旧版会怎样

**旧版会被自动卸掉，你的数据不会动。**

安装程序启动后会先找到机器上装过的旧版，**静默地**把它卸掉（不弹卸载向导、不用你确认），然后把新版装进**同一个目录**：

| 东西 | 结果 |
| --- | --- |
| 旧版程序文件 | **被删掉**（安装目录清空后重装） |
| 桌面 / 开始菜单快捷方式 | **保留**，指向新版 |
| 「已安装的应用」里的条目 | 更新成新版 |
| 安装目录 | **沿用上次装的目录**（更新时不问你装哪） |
| **配置 + 剪贴板历史 + 加密密钥** | **原封不动** |

**数据为什么一定不丢**：卸载旧版时，安装程序给旧卸载程序传了两个"保数据"的参数（`/KEEP_APP_DATA` 和 `--updated`）。打包脚本里写得很明确 —— **即使将来打开「卸载时删数据」这个选项，更新时也照样不删**。

**如果旧程序还开着**：安装程序会先试着关掉它；关不掉（文件被占用）会**重试 5 次、每次隔 1 秒**，还不行就弹框让你手动关。所以**装之前最好先「托盘右键 → 退出」**。

#### 三种情况下会有残留

1. **你以前用的是绿色版**（zip 解压出来的）—— 那不算"安装版"，安装程序根本不认识它。你当初解压在哪，那份旧程序就一直躺在哪，**要自己删**。这是最常见的残留来源。
2. **你装过上游官方版** —— 两者用的是**同一个程序标识**，所以装本分支时会把官方版**当成旧版一起卸掉**（反过来装也一样）。**别混着装。**
3. **数据目录永远不会被自动删** —— 这是好事（升级不丢历史），但要彻底清干净得手动删 `C:\Users\86183\AppData\Roaming\eSearch\`。

### 怎么卸载

「设置」→「应用」→「已安装的应用」→ 找到 **eSearch** →「卸载」。

> 卸载**不会删掉你的数据**。配置、剪贴板历史、加密密钥都还留在 `C:\Users\86183\AppData\Roaming\eSearch\`，以后重装回来历史还在。想彻底清干净，卸载后手动删掉那个文件夹。

### 数据不会丢

安装版和你用 `pnpm run start` 跑的是**同一个程序**，数据目录也一样：

```
C:\Users\86183\AppData\Roaming\eSearch\
```

所以**你的配置、剪贴板历史记录、加密密钥全部继承**，不会因为换了个启动方式就没了。

> 唯一注意：`pnpm run start` 和安装版**不要同时开**，两个程序会抢同一个剪贴板历史。用安装版之前先把命令行那个关掉。

### 打包失败了怎么办

| 现象 | 原因和处理 |
| --- | --- |
| 提示 `wmic 不是内部或外部命令` / 卡在打包中途 | 系统的 WMIC 组件缺失。这是 Windows 的问题，不是项目问题 |
| 报错里有 `Cannot find module 'electron'` | 先执行 `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，再 `pnpm install` |
| 报错提到文件被占用 | 先关掉正在运行的 eSearch（托盘右键 → 退出），再重试 |
| 打包很慢 / 像卡住了 | 第一次要下 100 MB 的运行时，**再等等**，最多 10 分钟 |
| 安装时提示「已安装更新的版本」 | 你机器上装过别的 eSearch。先去「设置 → 应用」把它卸载，再装这个 |

### 关于自动更新：默认关掉了

**这是故意的。** 本分支和上游共用同一套版本号（都从 `15.6.x` 往下排），而上游发版比本分支快。如果保留自动检查，上游一发新版，软件就会提示你"有新版本"，你一点下去就会用**官方版覆盖掉这个定制版**，剪贴板历史这些改动全都没了。

所以自动检查默认是**手动**（在「设置 → 更新 → 检查更新频率」里能看到）。想升级本分支，去 fork 的 [Releases](https://github.com/baichuanjiang2-cell/eSearch-paste/releases/latest) 下新包，或者手动同步上游代码后重新打包。

```
cd /d D:\SaveHub_Zcode\eSearch
pnpm run start
```

然后：**点任务栏上的「eSearch 剪贴板历史」按钮**。

cd /d D:\SaveHub_Zcode\eSearch
pnpm run dist

然后双击 `build\esearch_paste-15.6.1-win32-x64.exe` 安装。

打包完成后双击 `build\win-unpacked\e-search.exe`，以后都不用再开命令行了。
