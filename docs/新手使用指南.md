# eSearch 新手使用指南

这份文档写给第一次接触这个项目的人。全程照着做就行，不需要理解原理。

---

## 0. 先搞清楚一件事

你手上的是**源代码**，不是装好的软件。

所以不能像普通软件那样双击图标打开，必须先用一条命令把它"跑起来"。跑起来之后，它就是一个正常的 Windows 软件了。

好消息是：环境已经全部准备好了。Node、pnpm、Electron 都已经装好，你只需要执行启动命令。

---

## 1. 打开命令行窗口

**Windows 上最省事的办法（推荐）**：

1. 打开文件资源管理器，进入 `D:\SaveHub_Zcode\eSearch` 这个文件夹
2. 点击窗口顶部**地址栏**（显示路径的那一栏）
3. 把里面的路径全选删掉，输入 `cmd`，按回车
4. 会弹出一个黑色的命令行窗口，而且**已经在这个文件夹里了**

**其他办法**：按 `Win + R`，输入 `cmd`，回车，然后手动进入文件夹（见下一步）。

---

## 2. 进入项目文件夹

如果你用的是上面推荐的办法，这一步已经自动完成了，**直接跳到第 3 步**。

如果不是，在命令行窗口里输入下面这行，然后回车：

```
cd /d D:\SaveHub_Zcode\eSearch
```

> 注意：`cd` 后面有个空格，然后是 `/d`，再一个空格，然后是路径。  
> 如果你用的是 PowerShell 而不是 cmd，`/d` 要去掉，直接写 `cd D:\SaveHub_Zcode\eSearch`。

怎么确认自己进对地方了？输入 `dir` 回车，如果能看到 `package.json` 这个文件，就对了。

## 3. 启动软件

输入这一行，回车：

```
pnpm run start
```

然后会发生这些事：

1. 终端里刷出一堆文字 —— 这是**正常的**，它在编译代码
2. 大约 **10 秒左右**编译完成
3. 任务栏上出现一个**最小化**的按钮，名字是「eSearch 剪贴板历史」；右下角出现托盘图标

**不会有窗口自动弹出来**，这是正常的 —— 软件在后台待命，等你点任务栏按钮。

**重要：这个黑色终端窗口不要关。** 它是软件的"发动机"，关掉软件就退出了。

## 4. 启动后你应该看到什么

- **屏幕右下角**（托盘区，就是显示时间那一排图标里）多了一个 **eSearch 图标**，是彩色的
- **任务栏**上出现一个**最小化**的按钮，名字叫「**eSearch 剪贴板历史**」

**这个任务栏按钮就是剪贴板面板本身。** 点它，面板就出来。

不会自动弹出任何窗口，这是故意的 —— 软件在后台待命，等你点它。

> 任务栏上**不会**有搜索框那个窗口。那是「主页面」，只在 OCR / 搜索 / 翻译需要时才出现，关掉就消失。

如果你没看到托盘图标，点一下托盘区左边的 `∧` 小箭头，展开隐藏的图标看看。

## 5. 启动失败了怎么办

### 情况 A：报错里有 `GPU process isn't usable`，或者窗口一闪就没了

这是显卡加速在你的机器上不兼容。**关掉硬件加速就好了**：

1. 打开这个文件（复制路径到文件资源管理器地址栏）：


   ```
   C:\Users\86183\AppData\Roaming\eSearch\config.json
   ```
2. 用记事本打开它（右键 → 打开方式 → 记事本）
3. 找到这一行：
   ```json
   "硬件加速": true,
   ```
4. 把 `true` 改成 `false`，变成：
   ```json
   "硬件加速": false,
   ```
5. 保存（Ctrl+S），关掉记事本
6. 回到命令行，重新执行 `pnpm run start`

> 也可以等软件能正常打开后，在「设置 → 高级」里把「硬件加速」关掉，效果一样。

### 情况 B：提示 `'pnpm' 不是内部或外部命令`

你的电脑没装 pnpm。在命令行里执行：

```
npm i -g pnpm
```

装完再执行 `pnpm run start`。

### 情况 C：提示 `Cannot find module 'electron'`

Electron 的程序文件没下载全。在项目文件夹里执行：

```
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
pnpm install
```

这会从国内镜像重新下载（大约 100 多 MB），下完再启动。

### 情况 D：终端停住不动了

大概率是还在编译，**再等 20 秒**。第一次编译会慢一些。

## 6. 两个入口：托盘 + 任务栏

这是你要的第一个功能。**两个入口通向同一个东西 —— 剪贴板面板。**

**任务栏按钮**（名字是「eSearch 剪贴板历史」）

- 点它 → 剪贴板面板出现
- 点面板右上角的 **×** → 面板缩回任务栏，**按钮一直留着**，随时再点开

**托盘图标**（右下角）

- **左键点击**：走原有的截图功能（这是软件本来的设计）
- **右键点击**：弹出菜单，里面有「剪贴板历史」「暂停记录」等

**关键一点：点面板的 × 不会让软件退出，也不会让任务栏按钮消失。**

它只是收起来了。想真正退出，用托盘右键菜单里的「退出」。

**那搜索框呢？** 那是「主页面」，只在 OCR、搜索、翻译需要时才自动弹出，**不常驻任务栏**，关掉就消失。

## 7. 剪贴板历史怎么用

这是你要的第二个功能。

### 打开面板

三种方式，效果一样：

1. **点任务栏上的「eSearch 剪贴板历史」按钮**（最方便）
2. **右键点托盘图标** → 点菜单里的 **「剪贴板历史」**
3. 第一次启动时右下角弹出的**系统通知**，直接点它

面板是一个**独立窗口**，默认约 420 × 640，可以随意拖动和缩放。**位置和尺寸都会被记住**，下次打开还是老地方。

> 如果你换了显示器、拔了外接屏或者改了分辨率，导致上次的位置跑到屏幕外了，面板会自动回到屏幕中间，不会"消失不见"。

### 面板长什么样

顶部一条工具条，从左到右：

| 图标     | 作用                    |
| ------ | --------------------- |
| 搜索框    | 输入关键词筛选记录（只对文字和文件路径有效） |
| 暂停图标   | 临时停止记录（再点一下恢复）        |
| 垃圾桶图标  | 切换到「回收站」视图，看已删除的记录    |
| 清空图标   | 一键清空所有未固定的记录          |
| 文字图标   | **只看文本**（可多选）         |
| 图片图标   | **只看图片**（可多选）         |
| 文件图标   | **只看文件**（可多选）         |

后三个是**类型筛选**：点一下只看这一类，再点一下取消。可以同时选两个（比如"文字 + 图片"）。**一个都不选 = 全部**，这也是每次打开面板的初始状态。

> **为什么需要类型筛选？** 因为**图片没有文字可以搜**。搜索框对图片记录是无效的，想只看图片只能用这个按钮。

筛选和搜索可以**叠加使用**：先点「只看文本」，再在搜索框输入关键词，就是"在文本记录里搜关键词"。

下面就是记录列表，每条记录左上角写着**类型**（文本 / 图片 / 文件）和**时间**，右上角有三个小图标：

| 图标 | 作用                                         |
| -- | ------------------------------------------ |
| 复制 | 把这条内容放回系统剪贴板，之后在别的地方 Ctrl+V 就能粘贴           |
| 星星 | **固定**这条记录（固定后不会被自动清理淘汰）；已固定的会变成实心星，再点取消固定 |
| ×  | 删除 → 进回收站（不是真删）                            |

在**回收站**视图里，每条记录只有两个图标：**恢复**（还原回去）和**永久删除**（真删，不可恢复）。

### 亲手试一遍

1. 随便找一段文字，选中，Ctrl+C 复制
2. 打开剪贴板面板（如果已经开着，它会自动刷新，不用手动操作）
3. 你应该能看到刚复制的那段文字出现在列表最上面
4. 点那条记录右边的**复制图标** —— 内容回到剪贴板了
5. 点**星星**把它固定，它会保持在列表里不被清理
6. 点 **×** 删掉它，然后点工具条的**垃圾桶图标**进回收站，能看到它
7. 点**恢复**把它找回来，或者点**永久删除**彻底删掉

### 面板会不会挡住别的窗口？

**平时会置顶**，这样你随手唤出来它就在最上面，不会一碰别的窗口就被盖住。

**但 OCR、搜索、翻译的结果窗口出现时，面板会自动让到后面去**，不会挡住它们。这些窗口关掉后，面板又恢复置顶。

> 反过来说：**搜索窗口本身不置顶**，它是正常窗口。

### 复制图片和文件路径也支持

- 复制一张图片（比如在网页上右键复制图片）→ 面板里会出现缩略图
- 在文件资源管理器里选中一个文件，Ctrl+C → 面板里会显示这个文件的完整路径

### 第一次启动会有一条系统通知

右下角会弹一条通知，告诉你"已开始记录你复制的文字、图片和文件路径"。这是为了让你知道这个功能默认是开着的，**不是病毒行为**。点它可以直接打开面板。

## 8. 设置项说明

打开软件后，进「**设置 → 剪贴板历史**」，有这些选项：

| 设置项         | 默认值    | 说明                                        |
| ----------- | ------ | ----------------------------------------- |
| **记录剪贴板**   | 开      | 总开关。关掉就完全不记录了                             |
| **轮询间隔**    | 500 毫秒 | 多久检查一次剪贴板。数字越小越及时，但更耗电。**建议保持默认**         |
| **存储目录**    | 留空     | 留空就存在程序自己的数据目录里。改成别的文件夹后，**已有的记录会自动迁移过去** |
| **保留条数**    | 200    | 最多留多少条。固定住的记录和回收站里的**不算在内**。填 0 表示不限制     |
| **保留天数**    | 7      | 超过这个天数的记录会被清理。填 0 表示不限制                   |
| **清空剪贴板历史** | —      | 一个按钮，点它清空所有**未固定**的记录（固定的会留着）。会弹窗二次确认     |

改完这些设置**大约 1 秒后自动生效**，不需要重启软件。

## 9. 数据存在哪里 + 加密

### 默认位置

```
C:\Users\86183\AppData\Roaming\eSearch\剪贴板历史\
```

里面有三个东西：

| 文件                     | 内容                       |
| ---------------------- | ------------------------ |
| `index.bin`            | 所有记录的索引（文字内容、时间、是否固定等）   |
| `images\` 文件夹          | 图片记录的原始数据，每条一个 `.bin` 文件 |
| `clipboardHistory.key` | 加密用的密钥（在上一级目录）           |

### 加密说明

记录**不是明文存的**，用的是 **AES-256-GCM** 加密。密钥本身由 Windows 系统级的凭据保护（safeStorage）加密后才落盘。

**这意味着什么**：别人直接把 `index.bin` 拷走，是打不开的。

**但要如实告诉你两点**：

1. 这**只保护"落盘不明文"**。如果你的电脑已经中了木马、或者有人能直接操作你的电脑，这个加密挡不住。
2. 如果系统不支持加密（极少数情况），软件会**降级成明文保存**，同时在设置页顶部显示一条**黄色提示条**明确告诉你。**看到提示条就要知道：你的记录是明文的。**

> 自己手动删掉 `clipboardHistory.key` 会导致已有记录全部无法解密，**不要删**。

## 10. 怎么退出软件

**托盘图标右键 → 退出**。

注意：点剪贴板面板的 × **不会**退出，只会把它缩回任务栏 —— 这是故意的，为了让任务栏按钮一直可用。

主页面（搜索框那个窗口）的 × 会**真正关掉那个窗口**，但软件本身还在 —— 任务栏按钮和托盘图标都不受影响。下次 OCR / 搜索时它会再自动出现。

## 11. 给开发者：改代码之后怎么调试

| 命令                   | 作用                           |
| -------------------- | ---------------------------- |
| `pnpm run dev`       | 开发模式，改代码后界面会自动刷新，**平时开发用这个** |
| `pnpm run start`     | 构建后启动，接近真实运行效果               |
| `pnpm run typecheck` | 检查 TypeScript 类型错误           |
| `pnpm run lint`      | 检查代码风格问题                     |
| `pnpm run build`     | 只构建，不启动                      |
| `pnpm run pack`      | 打包成免安装程序（见第 12 节）            |

> 提示：这个项目的 `lint` 用的是 Biome。如果你看到大量关于换行符（CRLF / LF）的报错，那是 git 的 `core.autocrlf` 设置导致的，不是你的代码写错了。用 `npx biome lint src/` 可以只检查不格式化。

## 12. 打包成可执行程序（以后不用再开命令行）

上面 `pnpm run start` 的用法只适合自己用。如果你想**双击一个图标就打开**，需要"打包"一次。

打包**只需要做一次**，之后一直用打好的那个程序。

### 三步操作

**第 1 步**：打开命令行，进入项目文件夹（和第 1、2 步一样）：

```
cd /d D:\SaveHub_Zcode\eSearch
```

**第 2 步**：执行打包命令：

```
pnpm run pack
```

然后**耐心等**。这一步会做三件事：编译代码、下载 Electron 运行时（约 100 MB，第一次会慢）、把所有文件组装成程序。整个过程大概 **3 ~ 10 分钟**，终端里会刷很多文字，都是正常的。

> 打包需要的 5 个大文件（OCR 模型、ffmpeg 等，共约 155 MB）**已经提前下载好了**，这一步不会再重复下载。
>
> 也不需要配任何镜像 —— GitHub 直连是通的。

**第 3 步**：等终端出现类似 `building` 结束、命令提示符重新出现，就打包完成了。

### 打包产物在哪

打开 `D:\SaveHub_Zcode\eSearch\build\win-unpacked\` 文件夹，里面有 **`e-search.exe`** —— 这就是你的程序。

**用法**：双击 `e-search.exe`。

想放桌面的话，右键 `e-search.exe` → 发送到 → 桌面快捷方式。

> 整个 `win-unpacked` 文件夹是一个整体，**要拷贝就拷整个文件夹**，不能只拿 `e-search.exe` 一个文件（它旁边的那些 dll 和文件夹都是必需的）。
>
> 这个形态是**免安装**的：不写注册表、不进"添加或删除程序"。不想要了，直接删掉文件夹即可。

### 数据不会丢

打包出来的程序和你用 `pnpm run start` 跑的是**同一个程序**，数据目录也一样：

```
C:\Users\86183\AppData\Roaming\eSearch\
```

所以**你的配置、剪贴板历史记录、加密密钥全部继承**，不会因为换了个启动方式就没了。

> 唯一注意：`pnpm run start` 和打包版**不要同时开**，两个程序会抢同一个剪贴板历史。用打包版之前先把命令行那个关掉。

### 打包失败了怎么办

| 现象                            | 原因和处理                                     |
| ----------------------------- | ----------------------------------------- |
| 提示 `wmic 不是内部或外部命令` / 卡在打包中途 | 系统的 WMIC 组件缺失。这是 Windows 的问题，不是项目问题，见下方说明 |
| 报错里有 `Cannot find module 'electron'` | 先执行 `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`，再 `pnpm install` |
| 报错提到文件被占用                     | 先关掉正在运行的 eSearch（托盘右键 → 退出），再重试            |
| 打包很慢 / 像卡住了                    | 第一次要下 100 MB 的运行时，**再等等**，最多 10 分钟         |

### 关于自动更新：不会再提示了

**这是故意的。** 本分支的版本号仍然写着 `15.6.0`，和上游官方版一模一样。如果保留自动检查，上游一发新版，软件就会提示你"有新版本"，你一点下去就会用**官方版覆盖掉这个定制版**，剪贴板历史这些改动全都没了。

所以自动检查已经关掉了（改成手动）。想升级的话，需要手动同步上游代码后重新打包。
