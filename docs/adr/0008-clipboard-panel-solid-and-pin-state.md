# 面板退回纯色，固定的状态改成看得见

> **本决定取代 [ADR 0007](0007-clipboard-panel-liquid-glass.md) 的全部内容**，也取代 [ADR 0006](0006-clipboard-panel-edit-preview-glass-size.md) 第 3 条残留的部分（窗口材质）。0006 的其余三条（内容编辑、图片预览、尺寸档位）继续有效。
>
> [`docs/液态玻璃开发方案.md`](../液态玻璃开发方案.md) 保留为历史文档，不再代表当前实现。

## 背景

0007 把面板背景换成「自采集桌面 + 真折射」，技术上是成了的（像素级对齐误差 ≤1 设备像素，折射只落在边缘 28px 带内）。但它换来的是一整条重链路：

- 主进程每秒 `desktopCapturer` 截一次屏，JPEG 编码后再走 IPC 送进页面
- 渲染层多出三个背景层、三个前景层、一个 SVG 位移滤镜（含每帧重建的位移贴图）
- 设置页多出两个滑块
- 面板窗口挂着 `backgroundMaterial: "acrylic"` 与 `backgroundColor: "#00000000"`

用了一段时间后的结论很直接：**不想要了**。观感上它太"重"，而代价是持续的截屏与合成开销。

同时发现另一个真问题：**点星标固定一条记录，界面上没有任何变化**。代码里 `iconB("star", ...)` 无论是否固定都传同一张描边星，只改了 tooltip 文字 —— 而 `docs/新手使用指南.md` 早就写着"已固定的会变成实心星"。文档比代码超前，这是个必须补上的缺口。

## 决定

### 1. 液态玻璃整条链路删干净

不保留"默认关掉"的选项。理由：选了这个方向之后那条链路永远不会跑，留着就是死代码 + 两个没人调的滑块，而且它真的在跑（定时器 + 截屏）。历史都在 git 里。

删除范围：主进程的采集函数与定时器、两条 IPC 通道、`ClipBackdrop` / `ClipGeom` 两个类型、渲染层三层背景与三层前景、SVG 滤镜与位移贴图、`--lg-i` / `--lg-refract` 两个变量、设置页的两个滑块与「液态玻璃」分组、五条翻译条目、窗口的 `backgroundMaterial` 与透明底色。

### 2. 面板底色回到不透明的主题色

`body.glass` 直接取 `var(--bg)`，窗口不再有透明通道。**副作用**：面板不再跟随「样式 → 毛玻璃效果 → 不透明度」—— 窗口不透明时那层半透明没有任何东西可透，跟着走只是空操作。

### 3. 固定的状态给三处视觉提示

- **星标**换成实心并染成金色（新增 `star-fill.svg`）
- 卡片**左侧一道 3px 金色带**
- 卡片**底色混入 8% 金色**，微微偏暖

三处共用同一个 `--star-color`。金色写死在 SVG 里（`<img>` 吃不到 CSS 变量），所以那条规则上额外加了 `filter: none` —— 否则深色主题下 `--icon-color: invert(1)` 会把金色转成蓝色。

**回收站里不显示固定状态**：那里只有「恢复 / 永久删除」，固定状态没有对应操作，显示了反而让人想点。

## 后果

- **失去**"背景透出桌面"的观感，面板回到实心。这是主动选择的代价。
- **省掉**每秒一次截屏 + JPEG 编码 + 一次 IPC + 一个定时器。面板最小化期间不再有任何后台活动。
- 入场动画（列表淡入上浮）**保留**。它和液态玻璃无关，是列表本身的行为；类名从 `lg-appear` 改成 `list-appear`，免得留下误导性的前缀。
- 固定的记录本来就排到列表最前（`ClipHistory.list()` 的排序里 `pinned` 优先），所以固定后除了视觉提示，位置也会变。

## 没做到的

- 只在 Windows 上验证过。macOS / Linux 本来就没测（这个分支一直只跑 Windows）。
- 金色用的是单一色值 `#d99a2b`，没有为深色主题单独调。实测深色下卡片底色是 `oklab(0.2655 …)`、星标 `filter: none`，观感可以接受，但没有做数值上的对比度校验。
