# 移除全部录屏能力

Status: accepted

2026-11-16 决定：本分支不再提供任何屏幕录制能力。两套录制管线（MediaRecorder + FFmpeg 的经典录屏、WebCodecs + mediabunny 的超级录屏）、共用的悬浮控制条、录屏入口、设置页、快捷键、IPC 通道、打包资源、翻译词条、文档与测试一并删除。原因是本分支收敛为「识屏 · 剪贴板历史 · 翻译」，录屏不再属于产品范围；而「录屏」入口实际跑的就是超级录屏引擎，另有一套经典录屏兼容模式，两者共享悬浮条与大部分设置项，保留任何一半都会留下失效的半套功能。曾考虑只关入口保留代码、或只留经典录屏，都因共享状态无法干净切分而放弃。原先记录「三入口合并」的 0014 号决策随本次删除一同作废，编号不再复用。

## 停用术语

「录屏」「超级录屏」「经典录屏」「普通录屏」「区域录屏」「全屏录屏」均指已删除的概念，代码与文档不再引入这些词。名字相近但无关、必须保留的是「高级图片编辑」（`super_edit` / `superPhotoEditorInit`）、剪贴板的「暂停记录」，以及 `Record<...>` 泛型。

## 后果

- 截图与贴图保存共用 `save_file_path`、`ok_save` 通道，只收窄掉 `isVideo` 分支，其余行为不变。
- 打包不再下载 ffmpeg、不再声明 deb/rpm 的 ffmpeg 依赖；`gifenc`、`mediabunny` 依赖及锁文件条目移除。
- 启动时在 `fixSettingTree()` 清理旧配置里的 `录屏` 子树、`保存.保存路径.视频`、两条录屏快捷键及工具栏的 `record` 项。用户此前录好的视频文件不在软件管理范围内，不受影响。

## 实施记录

完整的改动清单、验证结果、遗留与待办见[录屏移除交接](../录屏移除交接.md)。实施期间还修好两处**与录屏无关**、但会挡住启动验证的既有问题：Electron 二进制未安装（`pnpm install --ignore-scripts` 所致）与 `lib/translate/translate.ts` 的 `readJson` 文件名校验，详见[本地启动与排障](../develop/本地启动与排障.md)。
