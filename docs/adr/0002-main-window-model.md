# 主页面窗口模型：关闭即隐藏 + 强制单窗口

> ⚠️ **本决定已被 [ADR 0004](0004-clipboard-history-standalone-window.md) 部分取代。**
> 「主页面常驻任务栏、关闭即隐藏、强制单窗口」的部分**作废**——实测发现任务栏图标绑定的是窗口而非标签页，导致「点任务栏图标打开剪贴板面板」这一需求无法实现。
> 现在由**剪贴板历史独立窗口**承担任务栏入口，主页面改回按需打开。
> 本文保留作为决策记录，下面「Consequences」中的第 1、2 条已不再成立。

eSearch 原本靠一个 `show: false` 的隐形窗口阻止程序退出（`main.ts:863`），主页面窗口关闭即销毁，且允许同时开多个。

本分支决定：启动时以**最小化**状态创建**唯一**的主页面窗口，它同时充当任务栏入口；关闭主页面只**隐藏**不销毁，并补上 `window-all-closed` 处理避免误退出。

理由：要让任务栏按钮常驻，就必须有一个生命周期与程序等长的真实窗口；多窗口会在任务栏堆出幽灵按钮；隐藏而不销毁则顺带解决了「所有窗口关闭即退出」的问题。

## Considered Options

- **保留多窗口，另建一个专用「壳」窗口常驻任务栏** —— 放弃：多一个窗口要同步生命周期，复杂度更高。
- **关闭即销毁 + 用 `window-all-closed` 阻止退出** —— 放弃：任务栏按钮会随窗口消失，与「常驻」矛盾。

## Consequences

- 设置项「主页面.复用」在本分支失去意义。
- 主页面窗口在程序启动时即被创建（加载 `editor.html`），启动开销略有增加。
- 那个隐形保活窗口可以移除。
