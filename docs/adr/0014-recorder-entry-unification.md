# 0014. 录屏入口统一：单入口 + 经典录屏兼容模式

日期：2026-11-15

## 状态

已采纳。

## 背景

截图框选工具条上并存三个录屏选项——「录屏（旧）」「普通录屏」「超级录屏」，命名不解释区别，用户分不清该用哪个（用户痛点 1）。旧管线（MediaRecorder + FFmpeg）与超级管线（WebCodecs + mediabunny）能力互补：超级管线画质与编辑器更强、同样支持 GIF/APNG 导出，但缺录制中暂停、倒计时自动录制与摄像头预览；旧管线独有这些能力与冷门容器格式，但整条链路依赖 FFmpeg，停止后的「转换 / 裁剪 / 合并」三行进度不可控，保存对话框打断心流。用户确认录屏痛点为全部五项：入口混乱、开始后控制窗消失、悬浮条交互差、停止后流程不透明、缺档位。

## 决策

1. **单入口**：截图工具条上只保留一个「录屏」。框选区域即进入**区域录屏**（超级管线 fixed 模式）；**录屏悬浮条**上提供区域 / 全屏切换（仅录制开始前可切）。旧管线从工具条移除，更名为**经典录屏**，降级为设置页的「经典录屏（兼容模式）」开关。
2. **超级管线补齐暂停**：录制帧循环暂停时停止追加帧、恢复时按暂停时长偏移时间戳，使导出视频无空洞；暂停/继续成为悬浮条核心按钮。
3. **录屏悬浮条 = 唯一控制面**：计时、暂停/继续、停止、取消、画质档位（帧率 30/60 × 画质 高/中/低，记住上次）、摄像头显隐、键鼠可视化开关、区域/全屏切换全部收进悬浮条；录制期间控制窗隐藏。键鼠可视化与摄像头维持默认关（与现状一致）。
4. **停止后流程**：区域录屏默认**直出**——转换进度可见、可取消，完成后自动保存到视频目录并系统通知（点击打开所在文件夹），不进编辑器；全屏录屏停止后进编辑器，编辑器内保存走同一套自动保存逻辑。设置提供「自动保存 / 每次询问」开关（`录屏.自动保存`，默认自动保存）。

## 替代方案

- **不补暂停**（超级模式暂停键置灰，要暂停用经典模式）：悬浮条作为唯一控制面却没有暂停，等于把核心按钮留在被降级的管线上，否决。
- **保留双入口**（「录屏」+「经典录屏」并列、仅改名加说明）：治不了入口混乱本身，否决。
- **只改文案**：三个选项的差异是结构性的，说明文案救不了选择成本，否决。

## 后果

- 入口语义唯一：**框一块 = 录这块**，全靠悬浮条续接；「录屏（旧）/ 普通录屏 / 超级录屏」成为历史术语。
- 经典录屏的独占能力（摄像头抠背景、倒计时、mkv/mov/ts 等容器）仍可达，但只在设置页开启兼容模式后出现，主界面不再为其保留位置。
- 停止后的默认心智从「停下来 → 找窗口 → 对话框」变为「停下来就行，通知里拿文件」；想要编辑器的人走全屏录屏。
- 超级管线的暂停实现依赖帧时间戳偏移，是本 ADR 中唯一的新增录制时行为，若上游超级录屏重构录制循环，此处需跟随。
