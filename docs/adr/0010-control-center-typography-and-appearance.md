# 控制中心采用得意黑展示层与外观模式快捷切换

Status: accepted

控制中心（Windows 桌面）采用得意黑承担品牌、页面标题、导航、按钮和栏目标题；列表与详情正文保持思源黑，详情标题保持思源宋，数字使用 Fraunces。字号按样张 C 档放大，侧栏工具和记录行副文再各加 1px。**外观模式**复用既有 `全局.深色模式` 的三档值（跟随系统 / 浅色 / 深色），在右上角用固定“对比度”图标循环切换，设置项显示名改为“外观模式”；右上角快捷动作、状态、暂停、外观与窗控统一为 34px，其他窗口的窗控保持 28px。

## Considered Options

- **全部文字使用得意黑** — 放弃：得意黑只有一种窄斜体，长文本可读性下降，且字体子集必须覆盖用户输入。
- **外观切换放在侧栏底部** — 放弃：用户选择放在右上角，和系统状态/窗控同组。
- **新建独立的主题存储** — 放弃：会与现有 `全局.深色模式` 设置重复，且两处状态容易不同步。

## Consequences

- 得意黑只需裁控制中心静态展示文案的用字（约 35KB），许可证随源码放在 `src/renderer/css/fonts/SmileySans-OFL.txt`，安装包内放在 `assets/licenses/SmileySans-OFL.txt`。
- 新增展示层文案时必须把新用字补进字体子集，否则缺字会回落到思源黑；正文和用户内容始终走思源黑，不受这个子集影响。
- 存储键沿用 `全局.深色模式`，避免迁移；界面术语统一为“外观模式”。
- 控制中心与其它窗口的窗控尺寸不同是有意为之：控制中心使用 34px，其它窗口维持 28px，避免逐窗重排。
