# 展示字体扩展到设置页并锁定同码点子集

Status: accepted

把 [ADR 0010](./0010-control-center-typography-and-appearance.md) 的字体分层从**控制中心**扩展到**设置**（含**控制中心**内的设置栏目与独立设置窗口两处形态）。得意黑只做**展示文字**，一共六处：页标题（h1）、栏目标题（h2）、侧边栏页面名、每条设置的名称、设置页按钮文字、搜索框占位文字；其余**正文文字**（说明文字、输入框里的值、快捷键键名、关于页正文）保持思源黑。英文界面同样走得意黑自带的拉丁字形，不再回落。**正文文字**与用户内容一条不动，因此不新增任何文案，翻译资源无需改动。

子集从"只覆盖控制中心静态文案"改为**与正文思源黑子集同码点**：同一份 7477 字 / 919,240 字节的用字表重新切一份得意黑，`@font-face` 与 `--display-font` 移到各页共用的 `src/renderer/css/fonts.css`，原来那份 345 字的 `.ui.woff2` 删除。

## Considered Options

- **再裁一份只含设置页用字的更小子集** — 放弃：设置项名称是"代码里的一条字符串"，新增一项就要补一次字；漏字时该行标题静默换成思源黑，没人会发现，直到用户截图问"为什么这行字体不一样"。同码点让"思源黑能显示 ⇒ 得意黑能显示"成为不变式，从此不需要人记得补字。
- **给设置页加一个字体开关** — 放弃：字体是设计决定，不是用户偏好；多一个设置项就多一处要翻译、要测试的状态。
- **连说明文字一起换得意黑** — 放弃：得意黑只有一种窄斜体，成段小字号可读性差，且会破坏 0010 已经定下的分层。

## Consequences

- 展示层字体子集从 345 字涨到 7477 字，安装包字体体积约 919KB（比按控制中心文案估算的 600–700KB 更大），换来的是新增文案零维护。
- 字体分层从此是**跨页面**的约定，不再属于控制中心：新页面要用得意黑，只允许落在**展示文字**那六类角色上，写 `font-family: var(--display-font)`，不写具体字体名。
- 判定一条文字属于展示还是正文，看的是**角色**（标题 / 名称 / 按钮 / 占位）而不是**字号**；同一行里名称是展示、紧跟其后的说明是正文。
- 独立设置窗口的默认宽度随本版从 900 改为 1060（见 [ADR 0012](./0012-visual-alignment-three-rules.md)），已有配置文件恢复的是自己记住的尺寸，不受影响。
