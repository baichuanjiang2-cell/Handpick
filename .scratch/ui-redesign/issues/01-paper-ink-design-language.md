# 01: 纸墨设计语言基础：主题变量 + 字体打包

**What to build:** 设计的"零件仓库"建好并可肉眼验收。亮/暗两套「纸墨编辑部」色彩变量（亮色：暖米白底、金 + 朱砂红强调、墨绿辅助；暗色：墨黑底、琥珀微光）落到既有的主题变量体系里，全部页面经现有主题链路自动生效；三套字体（标题思源宋体、正文思源黑体、数字 Fraunces）以子集形式打包进应用、离线可用，界面上能看到设计字形而非系统回落字体；圆角（6px）、间距、细墨线、阴影等统一参数成体系；设置里的主题选项扩为「亮色 / 暗色 / 跟随系统」三选一，默认亮色，选「跟随系统」时跟随 Windows 深浅色。UI 试验场页面出一页设计样本（字体、色板、基础形状），用户可直接打开看。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 亮色纸墨色板（暖米白底、金 + 朱砂红强调、墨绿辅助）与暗色色板（墨黑底、琥珀微光）以 CSS 变量定义，经现有主题链路注入全部页面
- [x] 思源宋体（标题）/ 思源黑体（正文）/ Fraunces（数字）常用字子集打包进应用，离线环境下界面字形正确、不掉系统字体；生僻字自动回落
- [x] 圆角、间距、细墨线分隔、阴影等统一设计参数成体系，供后续页面取用
- [x] 主题设置为「亮色 / 暗色 / 跟随系统」，默认亮色，「跟随系统」跟随 Windows 深浅色切换
- [x] UI 试验场页面展示一页设计样本（字体、色板、基础形状），可肉眼验收
- [x] 新增界面文本走 i18n 流程（source.json + tool.js）
- [x] `pnpm run format` / `pnpm run typecheck` / `pnpm run lint` 通过
