# 02: 控制中心样板：面板换皮 + 公共组件 + 统一标题栏

**What to build:** 剪贴板面板整体穿上「纸墨编辑部」外衣，成为用户验收的样板页。记录卡片（含固定记录的金色色带、星标、微暖底色，回收站）、搜索框筛选、类型筛选、放大查看、编辑记录、尺寸档位等全部既有交互原样保留、全部视觉重绘；顺手把散在多个文件里重复实现的基础控件（图标按钮、开关、对话框、表单控件等）收敛为一套公共组件（设置页表单控件工厂是最成熟的底子，向上提取），后续页面直接复用；窗口装上纸墨风格自绘标题栏（细墨线 + 金色圆点窗控）作为公共组件，供所有常规窗口复用。**本页是设计样板，用户点头后 04~08 才铺开。**
