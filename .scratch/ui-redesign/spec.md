# Spec: eSearch UI 重设计（纸墨编辑部）

## Problem Statement

用户对本软件的 UI 界面、设计美学、人机交互工程、使用和操作逻辑不满意。最核心的痛点只有一个：**入口不统一**——三种打开方式三种行为三种长相（点任务栏图标打开剪贴板面板、托盘左键直接进截屏框选、托盘右键弹出 20 项的系统原生文字菜单），而软件大部分功能和设置的入口藏在那个原生菜单里，既不协调也不顺手。次要的不满是整体视觉粗糙：没有统一的组件层（同一个图标按钮在 4 个文件里各写一遍且长得不一样）、截屏/录屏覆盖层用写死的黑白颜色不跟随主题、三套样式写法混用、常规窗口标题栏三种形态并存。

## Solution

从用户视角：

1. **入口统一**：点任务栏图标打开的窗口升级为**控制中心**——一进来还是剪贴板记录列表（现有形态不变），另加一条全量功能清单入口栏，从这里能到达软件的任何功能。托盘左键保留「快速截屏」快路径；托盘右键瘦身成 4 项（打开控制中心 / 快速截屏 / 暂停记录 / 退出）。
2. **功能不砍不藏**：每个功能都在全量功能清单里露名、一次点击可达；高频的放大、低频的缩小，没有一个是"失踪的"。
3. **视觉换新「纸墨编辑部」**：暖米白底 + 金色/朱砂红强调（把剪贴板面板已有的金星身份扩展为全局语言），标题思源宋体、正文思源黑体、数字 Fraunces，细墨线分隔、小圆角卡片；暗色模式为墨黑底 + 琥珀微光。默认亮色，提供"跟随系统"。
4. **窗口外观统一**：常规窗口（控制中心、主页面、设置、图片编辑、录屏编辑等）统一一种纸墨风格自绘标题栏；覆盖层（截屏、贴图、屏幕翻译、录屏提示）保持无边框异形。
5. **实施顺序**：设计语言基础 → 控制中心样板页（用户验收后）→ 逐页铺开 → 全局走查收尾。

## User Stories

1. As a 用户, I want 点任务栏图标后看到一个门面窗口（控制中心），从它的功能清单里能到达任何功能， so that 打开软件后"什么都能干"，不再依赖托盘右键那个土土的原生菜单。
2. As a 用户, I want 控制中心一打开仍然是剪贴板记录列表（形态不变）， so that 已有的肌肉记忆不被破坏。
3. As a 用户, I want 控制中心里有一条全量功能清单，每个功能都露名、一次点击可达， so that 没有功能是"找不到的"。
4. As a 用户, I want 高频功能在清单里排得更大更显眼、低频功能排得更小， so that 常用的东西顺手，界面又不拥挤。
5. As a 用户, I want 托盘左键点击仍然直接进入截屏框选， so that "快速截屏"这个高频快路径不被牺牲。
6. As a 用户, I want 托盘右键菜单瘦身成 4 项（打开控制中心 / 快速截屏 / 暂停记录 / 退出）， so that 右键菜单不再是一长串难扫的原生文字。
7. As a 用户, I want 现有的每一个功能都保留、一个不砍， so that 升级后能力不缩水。
8. As a 用户, I want 整个软件换上「纸墨编辑部」的视觉语言（暖米白底、金 + 朱砂强调、思源宋体标题、细墨线、小圆角卡片）， so that 软件看起来精致、有书卷气，不像廉价的系统设置页。
9. As a 用户, I want 亮色模式为默认主题， so that 第一次打开就是纸墨设计的灵魂面貌。
10. As a 用户, I want 暗色模式是墨黑底 + 琥珀微光， so that 夜里用不刺眼且气质统一。
11. As a 用户, I want 主题设置提供"跟随系统"选项， so that 软件跟着 Windows 的深浅色走。
12. As a 用户, I want 思源宋体/黑体以常用字子集打进安装包（约 3~5MB）， so that 任何机器上标题都是设计好的字形，不掉回普通系统字体。
13. As a 用户, I want Fraunces 数字字体随包， so that 界面上的数字有统一的设计感。
14. As a 用户, I want 所有常规窗口（控制中心、主页面、设置、图片编辑、录屏编辑）用同一种纸墨风格自绘标题栏（细墨线 + 金色圆点窗控）， so that 软件"只有一张脸"，协调统一。
15. As a 用户, I want 覆盖层（截屏、贴图、屏幕翻译、录屏提示）保持无边框异形形态， so that 全屏操作类窗口不被标题栏打扰。
16. As a 用户, I want 剪贴板面板的记录卡片、搜索框、类型筛选、放大查看、编辑记录、固定色带、回收站全部重绘成纸墨风， so that 用得最多的页面最先变美。
17. As a 用户, I want 界面里的按钮、开关、对话框等基础控件在所有页面长得一样， so that 软件不再有"拼凑感"。
18. As a 用户, I want 截屏工具条（框选、画笔、形状、滤镜、大小栏、取色器）重绘成纸墨风并跟随主题， so that 截屏时不被写死的黑白配色刺眼。
19. As a 用户, I want 截屏的操作方式完全不变， so that 已养成的截屏习惯不被打断。
20. As a 用户, I want 主页面（编辑器 + 浏览器标签条 + 内嵌翻译/AI 识图）换纸墨皮肤和统一标题栏， so that 日常主力页面观感一致。
21. As a 用户, I want 设置页 16 个分页换纸墨皮肤， so that 连设置都赏心悦目。
22. As a 用户, I want 设置的分页内容和分组完全不动， so that 找设置的习惯不被破坏。
23. As a 用户, I want 贴图、屏幕翻译、录屏提示三个覆盖层窗口视觉统一到纸墨语言， so that 全软件无死角。
24. As a 用户, I want 图片编辑器、超级录屏/视频编辑、旧版录屏三个大窗口换皮并用统一标题栏， so that 大工具窗口和其他页面气质一致。
25. As a 用户, I want 最后有一轮全局走查（间距、色彩、组件残留一致性检查）， so that 不留任何"没换到的角落"。
26. As a 用户, I want 用户文档（使用手册、新手指南）里的入口描述更新为新流程， so that 文档和软件行为不脱节。
27. As a 用户, I want 控制中心默认置顶、主页面存在时让出置顶的现有行为保持不变， so that 窗口叠放习惯不受影响。
28. As a 用户, I want 现有的 96 个 SVG 图标第一轮先不动， so that 先把骨架立起来，图标气质不合再单独处理。
29. As a 用户, I want 文档层面记录这次入口统一决策（修订 ADR 0004 的结论、更新 CONTEXT.md 术语）， so that 未来读代码的人能理解为什么任务栏按钮不再等于剪贴板面板。

## Implementation Decisions

- **控制中心**：剪贴板面板升级更名。窗口内保留现有记录列表交互（固定、回收站、类型筛选、搜索框筛选、编辑记录、放大查看、尺寸档位等语义全部不变），新增「功能入口栏」：软件全量功能清单，一行一个功能名、一次点击直达（高频项放大、低频项缩小）。清单以目录形式呈现，不砍不藏任何功能。
- **托盘**：左键行为保留为「快速截屏」（直接进入截屏框选）；右键菜单改为 4 项：打开控制中心 / 快速截屏 / 暂停记录 / 退出。原 20 项菜单中的每一项必须在控制中心功能清单中找到去向（逐项核对，零丢失）。
- **设计语言（纸墨编辑部）**：以 CSS 变量形式定义——亮色模式暖米白底、金 + 朱砂红强调、墨绿辅助；暗色模式墨黑底、琥珀微光。字体：标题思源宋体、正文思源黑体、数字 Fraunces。形状语言：6px 小圆角、细墨线分隔、纸条感卡片。强调色沿用剪贴板面板既有的金色星带身份（实心金星 + 金色色带 = "重点"的全局语言）。
- **主题**：亮 / 暗 / 跟随系统三选一，默认亮色。沿用现有 store 的主题配置链路，仅扩展取值。
- **字体打包**：思源宋体 + 思源黑体以常用字子集形式（约 3~5MB）随安装包分发；Fraunces 仅拉丁子集（<0.1MB）；生僻字自动回落系统字体。
- **窗口外观**：常规窗口统一纸墨自绘标题栏（细墨线 + 金色圆点窗控）；覆盖层保持无边框。标题栏做成公共组件供各常规窗口复用。
- **公共组件**：把散落各页重复实现的基础控件（图标按钮、开关、对话框、表单控件等）收敛为一套公共组件（其中设置页的表单控件工厂是最成熟的底子，向上提取）。这是预构（prefactor）：让后续换皮"改动变容易"。
- **实施顺序**：01 设计语言基础 → 02 控制中心样板（含公共组件与统一标题栏）→ **用户验收样板后** → 03 入口栏 + 托盘瘦身 + 术语落档；04~08 各页换皮（只被 02 阻塞、互相并行）→ 09 全局走查。
- **文档动作**：03 中更新 CONTEXT.md（「任务栏按钮 / 剪贴板面板」词条改写，新增「控制中心」「快速截屏」等词条），写新 ADR 记录入口统一决策并注明修订 ADR 0004 的结论。
- **翻译**：所有新增/修改的界面文本走既有 i18n 流程（source.json + tool.js），控制中心、托盘菜单等新文本均有翻译 id。

## Testing Decisions

- **不新增测试接缝**。唯一可用的自动化接缝是现有 `test/ui` 的整应用启动冒烟通道（备份配置 → 启动应用 → 观察 → 清理）。本项目 AGENTS.md 明确界面修改"不用测试"，且改动性质为界面与交互。
- **视觉验收是主要验收方式**：控制中心样板页完成后由用户人工验收（这是设计工作的正确验收形态）；各页面换皮后用户逐页确认。
- **外在行为核对**（人工，非自动化）：托盘右键 4 项齐全且各功能直达；对照旧 20 项菜单逐项确认去向、零功能丢失；点任务栏图标到达控制中心；快速截屏路径不变。
- **代码门禁**：每张票收尾跑 `pnpm run format`、`pnpm run typecheck`、`pnpm run lint`（既有流程）。
- **好测试的标准**（若未来补测试）：只测外在行为（窗口开出、菜单项存在、点击到达目标页），不测实现细节（DOM 结构、样式类名）。现有 `test/ui` 的 init/clip 是此类测试的先例。

## Out of Scope

- 96 个 SVG 图标的重绘（第一轮保留，样板页出来后视气质另议）。
- 功能增删：不加新功能、不砍旧功能；旧版录屏与超级录屏并存现状保留。
- 操作逻辑重做：除入口统一（托盘瘦身 + 功能清单）外，各页面内部的操作方式、快捷键、设置分组全部不动。
- 性能 / 内存 / 功耗优化（用户提过不满，但已确认本轮聚焦 UI/美学/交互；性能另行立项）。
- 换框架（Flutter / Tauri 等）：已评估并否决，不在讨论范围。
- 多语言翻译内容本身的补全（缺译问题已知，不属本次视觉重设计）。

## Further Notes

- 本次设计源于一次完整的设计树访谈（grilling），所有决策经用户逐项拍板：主矛盾排序 A(美学)>B(一致性)>C(交互)、入口方案 B、功能不砍不藏(目录式全量清单)、视觉方向「纸墨编辑部」、样板页=控制中心、窗口外观统一、字体打包子集。
- 「纸墨编辑部」的「记忆点」：批注感——重点内容像被朱砂笔圈点过；剪贴板面板既有的金星 + 色带语言扩展为全局"重点标记"。
- 用户为新手、独立开发者、私人 fork；文档面向"完全不懂技术"的读者，改动说明需按 AGENTS.md 的双段格式（专业版 + 通俗版）。
