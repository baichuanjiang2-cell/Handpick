# eSearch-paste

（中文 | [English](README_en.md)）

[![license](https://img.shields.io/github/license/xushengfeng/eSearch)](LICENSE)
[![release](https://img.shields.io/github/v/release/baichuanjiang2-cell/eSearch-paste?label=release)](https://github.com/baichuanjiang2-cell/eSearch-paste/releases/latest)

**eSearch 的私人定制分支。** 保留上游全部能力（截屏 / OCR / 搜索 / 翻译 / 贴图 / 屏幕翻译 / 以图搜图 / 滚动截屏 / 录屏），在它之上加了两样东西：

**剪贴板历史** —— 自己维护一份可检索的复制记录，文本 / 图片 / 文件路径都记，能搜、能就地改、能放大看图、能固定（固定后星标是金色实心）。

**控制中心** —— 点任务栏按钮打开的**整个软件的壳窗口**：左侧边栏导航 + 顶栏快路径，进来默认就是剪贴板历史；截屏、贴图、录屏、OCR 这些全在侧边栏的**工具组**里一键直达。打开软件 = 点任务栏图标，什么都能干。

> 上游 [xushengfeng/eSearch](https://github.com/xushengfeng/eSearch) 已明确拒绝「剪贴板管理」类功能（[Issue #317](https://github.com/xushengfeng/eSearch/issues/317) 与 [PR #515](https://github.com/xushengfeng/eSearch/pull/515) 均已关闭），所以这部分不打算回贡，只在本分支维护。

## 下载安装

到 [Releases](https://github.com/baichuanjiang2-cell/eSearch-paste/releases/latest) 下载，两个文件二选一：

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `esearch_paste-15.7.0-win32-x64.exe` | 约 186 MB | **安装包**（推荐）。有向导、**不需要管理员权限**、自动建快捷方式 |
| `esearch_paste-15.7.0-win32-x64.zip` | 约 246 MB | 绿色版，解压即用 |

> 文件名带 `esearch_paste-` 前缀是故意的 —— 官方版叫 `eSearch-<版本>-win32-x64.exe`，不加前缀会混。前缀**只改文件名**，程序内部的名字、安装位置、数据目录都没变。

**安装时 Windows 可能弹蓝色的「Windows 已保护你的电脑」** —— 点「更多信息」→「仍要运行」。这是因为没买代码签名证书（一年几百到上千元），个人开发的小工具都会这样，不代表有病毒。

**升级不会丢数据**：安装版和从源码跑的版本共用同一个数据目录 `%APPDATA%\eSearch`，配置、剪贴板历史、加密密钥全部继承。

> ⚠️ 本分支与上游官方版**共用同一个程序标识和同一个数据目录**。别两个同时运行、也别混着装 —— 会抢同一份剪贴板历史。

## 这个分支多了什么

| 能力 | 说明 |
| --- | --- |
| **控制中心** | 点任务栏按钮打开的**整个软件的壳窗口**（顶栏 + 左侧边栏 + 主内容区），任何功能都从这里到达。它本身就是任务栏按钮，点 × 只是缩回任务栏，不退出程序 |
| **剪贴板历史** | 自己维护一份可检索的复制记录，独立于系统当前剪贴板。文本 / 图片 / 文件路径都记，是控制中心的默认页 |
| **入口统一** | 托盘右键从 20 项瘦身成 4 项（打开控制中心 / 快速截屏 / 暂停记录 / 退出）；托盘左键保留「快速截屏」直接框选。全量功能收进控制中心的**工具组**，与托盘共用同一张动作表，不丢功能 |
| **纸墨设计语言** | 全软件统一外观：暖米白纸底、金色 / 朱砂强调、细墨线小圆角卡片；标题思源宋体、正文思源黑体、数字 Fraunces（常用字子集约 2.7 MB 随包分发，任何机器都不掉字形）。暗色模式为墨黑底 + 琥珀微光 |
| **编辑记录** | 文本与文件记录可就地改（图片不可）。改完若与另一条重复，两条会自动合并 |
| **放大查看** | 图片记录可弹层看原图，不再只看缩略图 |
| **固定 / 回收站** | 固定后不被自动清理淘汰；删除是进回收站，可恢复 |
| **类型筛选** | 只看文本 / 图片 / 文件，可多选；与关键词搜索叠加生效 |
| **尺寸档位** | 打开控制中心时用多大：默认 / 50% / 75% / 100% |
| **自定义数据目录** | `--userData` 参数 / `preload_config` 文件 / 便携模式三种入口。上游也有，但目录不存在时会启动崩溃，本分支修好了 |

### 上游原有功能（完整保留）

**截屏** · 截屏美化 · **滚动截屏** · **录屏 / 超级录屏** · **屏幕贴图** · **OCR 文字识别** · **以图搜图** · **翻译** · **屏幕翻译** · 离线 OCR 模型 · 全局快捷键 · 托盘

用法与上游一致，详细说明见上游的 [README](https://github.com/xushengfeng/eSearch#功能) 和[使用文档](https://github.com/xushengfeng/eSearch/tree/master/docs/use)。

> ⚠️ **用法差异有两处**：任务栏按钮现在打开**控制中心**（不再是主页面）；托盘右键只剩 4 项，全量功能在控制中心的工具组里。主页面（OCR / 搜索 / 翻译那个窗口）改成**按需打开、关闭即销毁**，不再常驻任务栏 —— 详见 [ADR 0004](docs/adr/0004-clipboard-history-standalone-window.md) 与 [ADR 0009](docs/adr/0009-entry-unification-control-center.md)。

## 控制中心

### 三个打开方式

1. **点任务栏上的按钮**（最方便）
2. 右键点托盘图标 → 「打开控制中心」
3. 第一次启动时右下角弹出的系统通知，点它

窗口默认约 **420 × 640**，可拖动、可缩放，**位置和尺寸会被记住**。换显示器导致位置跑到屏幕外时，会自动回到屏幕中间，不会"消失不见"。

### 窗口长什么样

三块：**顶栏 + 左侧边栏 + 主内容区**。

- **顶栏**：三个快路径 —— 快速截屏 / 自动识别 / 回到剪贴板，加纸墨三窗控（金 = 最小化、空心墨点 = 最大化、朱砂 = 关闭）
- **左侧边栏**：
  - 品牌区（软件名 + 版本号）
  - **页面栏目**：剪贴板 / 翻译 / AI 识图 / 设置 —— 点了在主内容区里换页，不出新窗口
  - **工具组**：全量功能的折叠分组（搜索与识别 / 录屏与贴图 / 窗口 / 帮助与系统），每个功能都露名、一次点击直达，默认展开
  - **主页面模式**：自动 / 搜索 / 翻译，决定打开主页面时先呈现什么
- **主内容区**：默认是剪贴板历史；翻译 / AI 识图 / 设置 在这里切换

**主页面**（编辑器）与**帮助**仍是独立窗口；截屏、贴图、屏幕翻译、录屏提示是全屏覆盖层，从工具组触发出去，不进壳。

### 外观：纸墨编辑部

全软件一套统一的「纸墨」外观：暖米白纸底、金色 / 朱砂强调、细墨线和小圆角卡片。标题用思源宋体，正文用思源黑体，数字用 Fraunces —— 三种字体的常用字子集约 **2.7 MB**，随安装包一起分发，断网、换机器都不掉字形，生僻字自动回落系统字体。

暗色模式是墨黑底 + 琥珀微光。换配色去 **设置 → 颜色**：主题色有纸墨等四套预设，也能逐项自定义；深色模式可选「浅色 / 深色 / 跟随系统」，默认浅色。

### 托盘只剩两件事

- **左键**：快速截屏（直接进框选，不带搜索延迟）
- **右键**：4 项菜单 —— 打开控制中心 / 快速截屏 / 暂停记录 / 退出

> 托盘左键行为由设置「点击托盘自动截图」控制（默认开）。

### 剪贴板栏目里能做什么

顶部工具条，从左到右：**搜索框**（只对文字和文件路径有效，图片没有文字可搜）、**暂停记录**、**回收站**、**清空未固定**，以及三个**类型筛选**按钮（文本 / 图片 / 文件，可多选，都不选 = 全部）。

每条记录卡片右上角：

| 图标 | 出现条件 | 作用 |
| --- | --- | --- |
| 眼睛 | 只有图片 | 弹层看原图（`Esc` 关闭） |
| 铅笔 | 只有文本 / 文件 | 就地编辑 |
| 复制 | 都有 | 放回系统剪贴板，之后在别处 Ctrl+V 即可 |
| 星星 | 都有 | 固定，不被自动清理淘汰。固定后变成**金色实心**，卡片左侧出现金色色带、底色微暖，并排到列表最前 |
| × | 都有 | 删除 → 进回收站（不是真删） |

> 图片没有"文字内容"可改，文本没有"原图"可看 —— 所以同一个位置只会出现一个图标。

**控制中心平时置顶**，但 OCR / 搜索 / 翻译的结果窗口出现时会自动让到后面去，不挡它们。

## 设置项

设置在控制中心侧边栏里（不再是独立窗口），改完约 **1 秒后自动生效**，不用重启软件。

设置 → 剪贴板历史：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **记录剪贴板** | 开 | 总开关 |
| **轮询间隔** | 500 毫秒 | 多久查一次剪贴板。越小越及时但更耗电，**建议保持默认** |
| **点击任务栏时的尺寸** | 默认 | 默认 / 50% / 75% / 100%。决定**打开控制中心**时用多大，百分比以屏幕工作区为基准；选百分比后，手动拖的大小不再被记住 |
| **存储目录** | 留空 | 留空存在程序数据目录；改成别的文件夹会**自动迁移已有记录** |
| **保留条数** | 200 | 固定住的和回收站里的不算在内；0 = 不限 |
| **保留天数** | 7 | 0 = 不限 |
| **清空剪贴板历史** | — | 清空所有**未固定**的记录，有二次确认 |

设置 → 颜色（外观）：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| **主题色** | 纸墨 | 四套预设色板（第一套就是纸墨），也可以逐项改亮色 / 暗色下的强调色、背景色、字色 |
| **深色模式** | 浅色 | 浅色 / 深色 / 跟随系统。深色是墨黑底 + 琥珀微光 |

## 数据存在哪

```
%APPDATA%\eSearch\剪贴板历史\
├─ index.bin                记录的索引（文字内容、时间、是否固定等）
├─ images\                  图片记录，每条一个 .bin 文件
└─ ..\clipboardHistory.key  加密密钥（在上一级目录）
```

**加密**：记录不是明文存的，用的是 **AES-256-GCM**；密钥本身由系统级凭据保护（safeStorage）加密后才落盘。别人直接把 `index.bin` 拷走是打不开的。

如实说明两点：

1. 这只保护"**落盘不明文**"。电脑中了木马、或者有人能直接操作你的电脑，这个加密挡不住。
2. 系统不支持加密时（极少数情况）会**降级成明文保存**，同时在设置页顶部显示一条**黄色提示条**。**看到提示条就说明你的记录是明文的。**

> 不要手动删 `clipboardHistory.key` —— 已有记录会全部无法解密。

## 已知限制

- **自动检查更新默认关闭**（改成手动）。因为本分支版本号与上游同源，上游一发新版就会弹「有新版本」并把人引向官方安装包 —— 装了就覆盖掉定制版。想升级需要手动同步上游代码后重新打包。
- **剪贴板历史方向不走上游**。上游已明确拒绝（Issue #317 / PR #515），本分支自行维护。
- **上游新增的修复不会自动进来**，需要手动合并。
- 只在 **Windows** 上测过。

## 从源码运行 / 打包

```bash
pnpm install

# 构建后启动（推荐）
pnpm run start

# 打包成安装包 + 绿色版
pnpm run dist
```

打包产物在 `build/`：

| 文件 | 大小 |
| --- | --- |
| `esearch_paste-<版本>-win32-x64.exe` | 约 186 MB（安装包） |
| `esearch_paste-<版本>-win32-x64.zip` | 约 246 MB（绿色版） |

> `pnpm run dev` 在这个项目里跑不通（原生 `.node` 库的问题），用 `pnpm run start`。
>
> 打包前需要 5 个资源（OCR 模型、ffmpeg 等，约 155 MB），首次会自动下载。
